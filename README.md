# Customer Trends & Shopping Behavior Analysis

An end-to-end data analysis project exploring customer shopping habits, product performance, discount sensitivity, and customer lifetime loyalty using **Python**, **SQLite**, **SQL**, and **Power BI**.

---

## 📌 Project Overview

This project analyzes 3,900 retail transactions to uncover actionable consumer insights. The workflow covers the full data lifecycle:
1. **Exploratory Data Analysis (EDA) & Data Cleaning**: Handled missing values, standardized schema, and engineered behavioral features in Python.
2. **Database Ingestion**: Modeled and loaded the cleaned dataset into an SQLite database (`database_customer.db`).
3. **Advanced SQL Analytics**: Executed 10 key business queries using CTEs, window functions, and aggregations.
4. **Automation**: Created a command-line script (`run_queries.py`) to parse and run SQL queries with formatted output.
5. **Business Intelligence**: Automated export to `customer_cleaned.csv` ready for ingestion into Power BI Online for executive reporting.

## 🔄 Data Pipeline & Workflow

### 1. Data Cleaning & Feature Engineering (`data_cleaning.ipynb`)
- **Missing Value Imputation**: Missing values in `Review Rating` were imputed using the median rating of each respective product `Category`.
- **Schema Standardization**: Column names formatted to lowercase snake_case (e.g., `Purchase Amount (USD)` $\rightarrow$ `purchase_amount`).
- **Feature Engineering**:
  - `age_group`: Categorized into `Young Adult`, `Adult`, `Middle-aged`, and `Senior` via quantile-based binning (`pd.qcut`).
  - `purchase_frequency_days`: Mapped purchase frequency text (e.g., Fortnightly = 14, Weekly = 7, Annually = 365) to numerical day values.
- **Redundancy Removal**: Dropped `promo_code_used` after confirming 100% equivalence with `discount_applied`.

### 2. Database Modeling (`database_customer.db`)
The cleaned DataFrame is written directly to an SQLite database table named `customer`.

### 3. Business Analytics (`sql_queries.sql`)
Answers 10 core commercial questions:
- **Q1**: Total revenue generated by Male vs. Female customers.
- **Q2**: High-value shoppers who utilized discounts yet spent above average.
- **Q3**: Top 5 products by average review rating.
- **Q4**: Average spend comparison between Standard and Express shipping.
- **Q5**: Revenue and average spend breakdown by subscription status.
- **Q6**: Products with the highest discount application rates.
- **Q7**: Customer segmentation based on previous order history (`New`, `Returning`, `Loyal`).
- **Q8**: Top 3 most purchased products per category using `ROW_NUMBER() OVER (PARTITION BY category ORDER BY ...)` window functions.
- **Q9**: Subscription propensity among repeat buyers (>5 previous purchases).
- **Q10**: Revenue contribution across age demographics.

### 4. Consolidated CLI Runner (`run_queries.py`)
Run all SQL queries directly from the terminal with clean formatting:
```bash
python3 run_queries.py
```

### 5. Power BI Reporting
The notebook exports `customer_cleaned.csv` on execution. This file is uploaded directly to **Power BI Online** to construct interactive executive dashboards with slicers for category, season, discount usage, and demographic segments.

## 🚀 Quickstart

1. **Clone the repository**:
   ```bash
   git clone https://github.com/arkadeycns/Customer-Shopping-Behaviour-and-Analysis.git
   cd Customer-Shopping-Behaviour-and-Analysis
   ```

2. **Set up virtual environment & install requirements**:
   ```bash

   source .venv/bin/activate
   pip install pandas
   ```

3. **Run the SQL queries**:
   ```bash
   python3 run_queries.py
   ```

4. **Launch the Notebook**:
   ```bash
   jupyter notebook data_cleaning.ipynb
   ```

## 📊 Key Insights Summary

- **Gender Revenue**: Male shoppers accounted for roughly 68% of total revenue ($157,890 vs. $75,191).
- **Customer Loyalty**: Over 79% of customers are categorized as `Loyal` (>10 previous purchases), representing the primary revenue engine.
- **Top Product Categories**: Clothing and Accessories lead overall transaction volume, with Jewelry, Sunglasses, Blouses, and Pants as top performers.
- **Discount Dynamics**: Discount rates average around 47%–50% across popular items such as Hats, Sneakers, and Coats without diminishing high-volume cart sizes.
- **Demographics**: Young Adults represent the largest individual spending segment ($62,143), closely followed by Middle-aged consumers ($59,197).
